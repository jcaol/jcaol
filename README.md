## 🧭 Engineering philosophy

A few principles guide the projects I work on.

**Own your data.** Prefer self-hostable systems, open formats, and infrastructure that users control.

**Design for interoperability.** Tools should work with existing workflows, not demand wholesale replacement.

**Keep humans in control.** Agents should make work easier to understand and manage, not introduce hidden complexity.

**Build from real problems.** Production experience is more useful than speculative feature lists.

**Make maintenance sustainable.** Reliability, security, operational simplicity, and clear documentation matter as much as features.
